# Texas Top 10

A website showcasing the top 10 places in cities across Texas.

Plain HTML, CSS and JavaScript with no build step, so it can be hosted on GitHub Pages as-is.

## Run locally

```powershell
python -m http.server 5173 --bind 127.0.0.1
```

Then open http://127.0.0.1:5173

## Project layout

- `index.html`: page shell
- `styles.css`: all styling
- `map.js`: the interactive Texas map (outline, city markers, zoom)
- `app.js`: routing (`#/`, `#/city/<slug>`, `#/method`, `#/about`), rendering and animations
- `data/cities.js`: the city lists. Add a city by adding an entry here, including its `lat`/`lon` for the map.
- `data/photos.js`: photo URLs and credits (generated by `tools/fetch_photos.py`)
- `data/geo.js`: map shapes (generated by `tools/build_map.py` from US Census TIGERweb data)
- `tools/photo_overrides.json`: which Wikipedia article (or Commons file) to take each place's photo from
- `TASKS.md`: what's done and what's next

When you change CSS or JS, bump the `?v=` number on the links in `index.html` so browsers load the new files.

## Photos

Photos are Wikimedia Commons images under free licenses, shown from Wikimedia's servers with a credit
under each one and on the Photo Credits page. After adding or renaming places, add them to
`tools/photo_overrides.json` and run:

```powershell
python -I tools/fetch_photos.py
```
